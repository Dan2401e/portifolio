## 🚀 Sobre o projeto

O projeto consiste em uma página de portfólio pessoal desenvolvida utilizando tecnologias web fundamentais.

A interface apresenta:

- 👤 Seção de apresentação
- 🛠️ Lista de habilidades
- 📂 Projetos desenvolvidos
- 🔗 Links diretos para projetos
- 📬 Formulário de contato
- 📱 Layout responsivo
- 🖥️ Adaptação para diferentes tamanhos de tela

O objetivo é reunir meus trabalhos em um único lugar e facilitar a visualização da minha evolução como desenvolvedor.

## 📱 Responsividade

O projeto possui adaptação para dispositivos com telas menores.

Foram utilizadas **Media Queries** para modificar elementos como a tabela de projetos quando a largura da tela é reduzida.

Isso permite uma melhor experiência de navegação em:

- 💻 Computadores
- 📱 Smartphones
- 📟 Tablets

## ⚙️ Como executar o projeto

### 1. Clone o repositório

```bash
git clone URL-DO-SEU-REPOSITORIO
```

### 2. Entre na pasta

```bash
cd Portifolio
```

### 3. Abra o projeto

Você pode simplesmente abrir:

```text
index.html
```

no navegador.

---

## 🔴 Executando com Live Server

Para uma melhor experiência durante o desenvolvimento, você pode utilizar a extensão **Live Server** no Visual Studio Code.

1. Abra a pasta do projeto no VS Code.
2. Instale a extensão **Live Server**.
3. Clique com o botão direito em `index.html`.
4. Selecione **Open with Live Server**.

O projeto está configurado para utilizar a porta:

```text
5501
```
